Code used for optimizations in the manuscript "Effective Atom Theory: Gradient-Driven Materials Design" are stored here. The "DFT_EAT" folder houses the code used to optimize the high entropy rock salt oxide and find the Cu-Pd phase diagram using the DFT implementation of EAT. The "MLIP_EAT" folder houses the code used to optimize the Cu-Pd phase diagram and NaCl using the FARIChem implementation of EAT.

The source code for the DFT version of EAT is located here: https://github.com/StunningLlama/jdftx. When downloading this codebase, checkout the jdftxmix branch.
