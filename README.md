Code used to optimize the high entropy rock salt oxide in the paper "Effective Atom Theory: Gradient-Driven Materials Design" are stored here. The "HERSO_DFT" folder houses code and data from the DFT-based EAT optimization of the high entropy rock salt oxide. The "Cu-Pd_DFT" houses code and data from the DFT-based EAT optimization of the Cu-Pd convex hull. The "Cu-Pd_MLIP" houses code and data from the FAIRChem-based EAT optimization of the Cu-Pd convex hull. Finally, the "NaCl_MLIP" houses code and data from the FAIRChem-based EAT optimization of NaCl.

A short tutorial on how to use JDFTx_EAT (the version of the DFT software package JDFTx that has effective atom theory (EAT)) is also included. To download JDFTx_EAT, visit https://github.com/StunningLlama/jdftx and checkout the jdftxmix branch.
